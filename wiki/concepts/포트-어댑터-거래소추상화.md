# 포트-어댑터 거래소 추상화

> 순수 전략 엔진과 브로커 API 어댑터를 분리(헥사고날)해 거래소를 스왑 가능하게 하는 구조. 트레이딩 공통.

## 무엇 / 언제 쓰나
새 거래소/브로커를 붙이거나, 백테스트와 실거래에서 같은 전략 엔진을 재사용할 때.

## 정본 구현 (canonical)
- **헥사고날 구조** — `StockDante/` — 순수 전략(`dante/`)과 API 어댑터(`poc/`,`adapters/`) 분리. `dante/broker.py`(Broker + MockBroker), 해외는 `adapters/kis_overseas_broker.py`로 동일 엔진 재사용.
- **추상 거래소 인터페이스** — `Crypto/api/base_api.py:7-60` — ABC + `OrderType`/`OrderSide`/`OrderStatus` Enum, `APICredentials`/`OrderRequest` dataclass, HMAC 서명 준비.

## 다른 구현 / 변형
- `mt5/strategies/base.py` — 전략 베이스 추상화 + `double_bb.py` 구현.
