# 네이버 자동로그인 — 패스키 오제출 · 버튼셀렉터 · 로그인상태유지

> Enter로 로그인 제출하면 "패스키 로그인에 실패했어요"로 튕기고, 로그인돼도 재기동하면 로그아웃 → 비번 버튼(#loginBtn_*)을 명시 클릭 + "로그인 상태 유지"(#loginStay) 체크로 무인 로그인 세션을 프로필에 영속.

## 무엇 / 언제 쓰나
네이버 `nidlogin`을 무인 자동화로 로그인시켜 세션을 크롬 프로필에 영속시킬 때(쇼검·트래픽·수집 노드). 2026-09 네이버 로그인 페이지 개편으로 옛 셀렉터·Enter 제출이 **에러 없이 조용히 깨진다** — 레이트리밋/계정차단으로 오진하기 쉬우니 실패화면을 먼저 캡처해 원인을 눈으로 확인한다.

## 주의점 / 함정 (이름 붙인 실패)
- **"패스키 오제출"**: 비번 버튼(#loginBtn_*)을 못 찾아 `keyboard.press("Enter")`로 제출 → 네이버가 패스키(WebAuthn) 로그인을 시도 → `.form_message.error` "패스키 로그인에 실패했어요"로 실패, URL은 nidlogin 잔류. 증상만 보면 레이트리밋/차단으로 오판(실제는 셀렉터 미스). 진단=`page.screenshot` + body의 `[class*=error]` 텍스트 덤프.
- **"세션쿠키 미영속"**: #loginStay 미체크 시 NID_AUT/NID_SES가 세션쿠키로만 발급 → patchright persistent context 종료 시 디스크 미저장 → 다음 기동 로그아웃. 검증=빈 프로필로 1회 로그인 후 같은 프로필 재실행 시 "이미 로그인 상태" 나오면 영속 OK.
- **"쿠키파일=로그인 오판"**: 러너 게이트(enforceShoppingProfileGate)가 `Default/Network/Cookies` 파일 존재만 보고 세션 유효성은 확인 안 함 → 만료 프로필도 통과 후 착지 단계서 LOGIN_REDIRECT. 신선 로그인 or 런타임 재로그인 필요.
- **노드 npx 차단**: 노드 PowerShell ExecutionPolicy가 `npx.ps1`을 막음(`UnauthorizedAccess`) → `npx.cmd` 사용.
- **신원 __NODE__**: 골든이미지 `EQUIPMENT_NAME` 플레이스홀더 미치환 시 텔레메트리가 `node_id=__NODE__`로 새어 노드가 오프라인으로 오인됨(실제론 정상 가동) → `setx EQUIPMENT_NAME <실제이름>` + 재시작.

## 배제된 접근 (dead-end)
- **Enter/키보드 제출 폴백** — 비번 버튼 없을 때 `keyboard.press("Enter")`는 패스키를 트리거해 실패. 제거하고 버튼 못 찾으면 명시 실패(exit 5)로 처리.
- **옛 셀렉터 `#log.login` / `#keep`** — 2026-09 개편으로 둘 다 사라짐. 각각 `#loginBtn_*` / `#loginStay`로 대체.
- **로그인 프로필 노드간 복사(zip 배포)** — DPAPI로 그 PC·계정 키에 묶여 복사 시 로그아웃([[크롬프로필-DPAPI-로그인-이식불가]]). 각 노드 로컬 로그인만 유효.
- **`page.fill()` 입력** — 붙여넣기/자동입력 탐지에 걸림. 한 글자씩 `keyboard.type`.
