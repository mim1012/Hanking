# 실험-그래프-오케스트레이션
> 원격 노드 함대에서 도는 A/B 실험을 "프롬프트→루프→그래프"의 그래프 층으로 올린 패턴. 상태는 DB, 엣지는 코드, 사람은 escalated/judged 두 노드에서만 개입한다.

## 무엇 / 언제 쓰나
사람(또는 LLM 세션)이 발화→로그 확인→진단→고침→재발화 루프를 손으로 돌리고 있고, 그 실패의 대부분이 **이미 이름 붙은 결정적 실패**(폴더 누락, 끊긴 세션, 잘못된 커밋, hang)일 때. 최종 지표가 느리게 오는(하루 1회 순위 갱신) 실험에서 "지표가 유효하려면 dose가 충분해야 한다"는 게이트를 강제하고 싶을 때. 트래픽 turafic 뿐 아니라 순위 sellermate·파이프라인 zero-landing 처럼 원격 Windows 노드 + Supabase 텔레메트리 조합이면 그대로 포팅 가능.

## 주의점 / 함정
- **「부분 발화 무감독 트래픽」**: 노드 A 발화 성공·노드 B 실패로 실험이 escalated 가 되면 A 의 예약작업이 살아서 2분 뒤 트래픽이 나간다. escalate 전에 성공 노드의 schtasks 삭제+러너 kill 필수(`exp-graph.mjs:419` 부근 DISARM).
- **「0행 영원 진행중」**: 비율 증상은 `min_rows_for_pct` 아래면 판정을 안 하므로, match 오타(→ SQL `false`)나 러너 정지로 텔레메트리 0행이면 아무 증상도 안 나고 "dose 진행중"만 반복. 시간 기반 `NO_TRAFFIC`(no_traffic_h) 이 따로 필요.
- **「빈 배열 → array[null]」**: `array[${ids.join(',') || 'null'}]` 은 빈 배열을 원소 1개(NULL) 배열로 만들어 unnest 에 유령 행, `array_length` 오보고. 빈 경우는 `'{}'::bigint[]`.
- **「dry-run 이 청정 위장」**: 고침을 건너뛴 뒤 증상을 `[]` 로 강제하면 미리보기가 항상 "clean → FIRE". 건너뛰면 증상도 그대로 둔다.
- 429·로그인벽·MNF 폭증은 REPAIR 대상이 아니다 — 러너 정지 후 ESCALATE. 두드리면 악화된다([[캡차-차단-대응]]).
- 순위는 dose 지배(슬롯당 200~440타는 개선, 20타는 노이즈) — DOSE 게이트 없이 RANK_DELTA 로 가면 노이즈를 결론으로 쓴다.

## 배제된 접근 (dead-end)
- **채팅 세션·메모리 파일을 상태 저장소로**: 세션마다 "어제 어디까지 갔는지"를 재구성하느라 개입이 들어가고, 노드/슬롯 정의가 스크립트 6개에 흩어져 드리프트. → DB 테이블 + 정의 JSON.
- **틱마다 LLM 판단**: 결정적 실패를 매번 LLM 이 진단하면 토큰·지연·오진(키/RLS/세션 오판 이력). LLM 은 미지 증상(escalated) 진단에만.
- **REPAIR 무제한 재시도**: 같은 원인에 세 번째 시도는 성공한 적이 없다(전역 안티루프 룰). repair_max=2.
