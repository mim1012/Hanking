# 시각 회귀 베이스라인 게이트 (디자이너 표현 유실 자동 탐지)

> 2인 협업(디자이너/백엔드)에서 병합 중 표현(마크업·스타일·섹션 배치) 유실을 CI 픽셀 diff로 자동 차단하는 패턴. BAGJO1에서 "머지 후 며칠짜리 드리프트 전수조사"를 몇 분짜리 CI 빨간불로 대체.

## 무엇 / 언제 쓰나
디자이너 정본과 백엔드 배선이 같은 파일을 흐르는 협업에서, 병합·배선 작업이 표현을 조용히 되돌리는 사고 방지. 골든플로우 대표 페이지 × 뷰포트를 Playwright `toHaveScreenshot`으로 고정.

## 정본 구현 (canonical, BAGJO1 main 2026-07-12)
- **스펙** — `BAGJO1/tests/golden/visual.spec.ts` (7경로×2뷰포트=14장 상한 고정, `maxDiffPixelRatio: 0.01`, admin은 로그인 후 `tbody` 마스크, CI(Linux) 전용 skip 가드)
- **비교 워크플로** — `BAGJO1/.github/workflows/visual.yml` (Vercel `deployment_status` success·Preview 트리거 → 그 배포 URL 대상 비교, sha 단위 concurrency)
- **베이스라인 갱신** — `BAGJO1/.github/workflows/update-baselines.yml` (PR `update-baselines` 라벨 또는 dispatch → CI가 `--update-snapshots` 후 브랜치에 자동 커밋. 배포 URL은 GitHub deployments API로 environment=Preview 필터 해석)
- **운영 규칙** — `BAGJO1/AGENTS.md` §8-1 병합·시각 회귀 프로토콜 (디자이너 PR 빨간불 = 승인 체크포인트, 백엔드 PR 빨간불 = 진짜 드리프트 / 콘텐츠(재시드) PR은 베이스라인 갱신 동반 / "표현" = 색·뱃지·텍스트 + 섹션 위치·순서)

## 실증된 함정 (전부 실측)
- **베이스라인은 CI(Linux)에서만 생성** — 로컬 Windows 스냅샷은 폰트 렌더 차이로 전량 오탐. 스냅샷 파일명 `-linux` 접미사가 충돌 방지.
- **Vercel Preview에서 `networkidle` 대기 금지** — 프리뷰 툴바 웹소켓이 상시 연결이라 idle이 영원히 안 옴(14/14 타임아웃). `load` + 고정 정착 대기 + 전체 스크롤(whileInView 트리거) 사용.
- **workflow_dispatch는 기본 브랜치에 워크플로가 있어야 UI 노출** — 부트스트랩은 `pull_request: [labeled]` 트리거로 해결(PR 브랜치 워크플로로 실행됨).
- 공개 리포면 테스트 계정 폴백 하드코딩 금지 — secret 주입 + 미주입 시 해당 촬영 skip.

## 검증 방법 (게이트를 게이트답게)
고의 훼손 커밋(배경색 1개 변경) → 해당 페이지 2장만 빨간불(diff 0.20) & 나머지 12장 통과 → revert → green. 이 왕복을 실증해야 도입 완료로 친다.
