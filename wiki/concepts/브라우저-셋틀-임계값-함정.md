# 브라우저-셋틀-임계값-함정
> 외부 브라우저(Chrome/Samsung Internet) 페이지 안정 판정 시, **브라우저 UI 자체 텍스트가 임계값을 넘으면 웹 콘텐츠가 전혀 없어도 "안정"으로 통과**한다.

## 무엇 / 언제 쓰나

접근성 서비스(`rootInActiveWindow`)로 페이지 로드 완료를 판정하는 모든 앱 자동화 프로젝트.
외부 브라우저의 UI(툴바, URL바, 탭 스트립, 메뉴)가 텍스트 노드를 만들기 때문에,
"텍스트가 N자 이상이면 로드됨" 판정의 N이 낮으면 빈 페이지에서도 통과한다.

## Canonical 구현

- **발견**: `naver_turafic_samsung` — Chrome UI ~239자가 `MIN_SETTLED_TEXT_LENGTH=200`을 넘어 blank 25% 발생
- **수정**: `ExternalChromeBrowserSession.kt:199` — 200→600으로 상향 (커밋 `63447995`)
- **검증 기준**: `chrome-local-verify.mjs:95`의 `MIN_RENDER_CHARS=500`과 정합

## 패턴

```
임계값 설정 원칙:
  MIN_SETTLED > 브라우저 UI 텍스트 최대값 (실측 필요)
  MIN_SETTLED < 실제 페이지 텍스트 최소값 (SERP 최소 ~1000자)
  → 안전 구간: 500~800

판정 신뢰도 순서:
  1. CDP URL 안정 (가장 신뢰) — URL이 바뀌지 않으면 로드 완료
  2. 접근성 텍스트 길이 (폴백) — 위 함정 주의
  3. 고정 sleep (최하) — 불확실 + 느림
```

## 실증 데이터

| 조건 | 텍스트 | 판정 (200 기준) | 판정 (600 기준) |
|---|---:|---|---|
| Chrome UI만 (빈 페이지) | ~239 | ✅ 통과 (오판) | ❌ 대기 (정확) |
| 네이버 SERP 최소 | ~1,000 | ✅ 통과 | ✅ 통과 |
| 네이버 SERP 평균 | ~5,000 | ✅ 통과 | ✅ 통과 |
